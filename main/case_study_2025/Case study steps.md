# Case study 2025

This document explain how to run the code for the 2025 case study of the MS5 asset performance program.

## Set up environment
The guide covers execution in the terminal using `git bash` for windows or the regular terminal for WSL.

Start by changing the directory to the root of the repository:
```
cd <your path here>/ms5-asset-performance
```

Create and activate a new virtual environment named `.venv` (or whaterver name you like):
```
python -m venv .venv
source .venv/bin/activate
```

Install the necessary requirements:
```
pip install -r requirements.txt
```

## Data preparation

First create the datasets needed for training the surrogate model and for the Monte Carlo Simulation (MCS). The former samples are drawn from a uniform distribution and the latter from a normal one, parameterized by the prameters given in `/main/case_study_2025/data/parameter_distributions.csv`. You can achieve this by running:
```
python -m main.case_study_2025.prepare_samples.generate_samples --n_mc_samples 10000000 --n_srg_samples 10000
```

You can change the number of drawn samples for the MCS and surrogate training by adjusting the respective argument. The samples are automatically stored in `main/case_study_2025/data`.
This script also calculates the D-SheetPiling results for each of the drawn surrogate samples. The results are also stored in the same directory.

The case study works with synthetic data (corrosion measurements and deformations per time step), which is generated by running:
```
python -m main.case_study_2025.prepare_samples.generate_setting --interval 1
```
The argument `interval` controls the year interval between observations.
